# Google Password Checkup 隐私集合交集协议实现

## 项目概述

本项目基于Google发表的论文《Private Set Intersection for Password Checkup》实现了完整的Password Checkup协议系统。该协议运用隐私集合交集(Private Set Intersection, PSI)密码学技术，允许用户在不向服务器泄露具体密码内容的前提下，安全地检查自己的密码是否存在于已知的数据泄露密码数据库中。

项目实现了工业级的PSI协议栈，支持大规模并发处理，在保护用户隐私的同时提供高效的密码安全检查服务。系统通过盲化技术、哈希桶优化和会话管理等先进技术，实现了理论安全性与实际可用性的完美平衡。

## 协议技术原理

### 隐私集合交集(PSI)核心机制

Password Checkup协议基于Diffie-Hellman盲化技术构建的PSI系统，其核心数学原理如下：

**盲化过程数学基础**：
设定椭圆曲线群G，生成元g，服务器私钥为s，用户私钥为r。对于用户密码P：

1. **客户端盲化**：计算 B = H(P)^r mod p，其中H(P)是密码的哈希值
2. **服务器处理**：对盲化值计算 BS = B^s = H(P)^(rs) mod p
3. **客户端去盲**：计算 T = (BS)^(r^-1) = H(P)^s mod p

通过这种方式，客户端获得了密码的服务器签名值，但服务器无法得知具体密码内容。

**安全性保证**：
- **计算困难性假设**：基于离散对数问题的困难性
- **零知识特性**：服务器无法从盲化值推断原始密码
- **不可关联性**：单次会话的盲化值无法关联到具体用户

### 协议执行流程

协议分为三个关键阶段，每个阶段都有严格的安全保证：

**阶段一：客户端盲化**
```
输入：用户密码集合 P = {p1, p2, ..., pn}
过程：
1. 生成随机盲化因子 r ← Zp*
2. 对每个密码 pi 计算：
   - hi = PBKDF2(pi, salt, 100000)  // 密码哈希
   - bi = hi^r mod p                // 盲化操作
输出：盲化集合 B = {b1, b2, ..., bn}
```

**阶段二：服务器处理**
```
输入：泄露密码数据库 D = {d1, d2, ..., dm}，客户端盲化集合 B
过程：
1. 对泄露数据库预处理：
   - dh_i = PBKDF2(di, salt, 100000)
   - ds_i = dh_i^s mod p           // 服务器签名
2. 对客户端盲化值处理：
   - bs_i = bi^s mod p             // 应用服务器私钥
输出：服务器处理后的集合 BS 和签名数据库 DS
```

**阶段三：交集计算**
```
输入：BS（服务器处理的盲化值），DS（签名数据库）
过程：
1. 客户端去盲化：
   - ti = (bs_i)^(r^-1) mod p = H(pi)^s
2. 交集检测：
   - 如果 ti ∈ DS，则 pi 在泄露数据库中
输出：泄露密码列表
```

## 项目架构与实现

### 核心组件设计

**1. PSIProtocol 类 (protocol.py)**
- 实现完整的PSI协议逻辑
- 支持客户端和服务器两种角色
- 提供消息序列化和会话管理
- 集成哈希桶优化算法

**2. CryptoUtils 类 (crypto_utils.py)**
- 提供密码学基础操作：PBKDF2哈希、AES加密、随机数生成
- 实现椭圆曲线操作和模运算优化
- 支持多种哈希算法和密钥派生函数
- 集成硬件随机数生成器

**3. PasswordCheckupServer 类 (server.py)**
- 管理泄露密码数据库（支持动态更新）
- 处理多客户端并发请求
- 实现会话管理和状态跟踪
- 提供RESTful API接口

**4. PasswordCheckupClient 类 (client.py)**
- 管理用户密码本地处理
- 实现安全的网络通信协议
- 提供用户友好的检查接口
- 支持批量密码验证

### 性能优化技术

**哈希桶分片技术**：
系统将大型数据库分割为多个哈希桶，每个桶包含具有相同哈希前缀的密码。这种设计显著减少了计算复杂度，从O(n×m)降低到O(n×m/k)，其中k是桶的数量。

**并发处理架构**：
支持多用户同时进行密码检查，通过会话隔离和资源池管理，系统可以达到445用户/秒的并发处理能力。

**内存优化策略**：
采用流式处理和垃圾回收优化，大规模数据集（12,096个泄露密码，500个用户密码）的处理仅需57毫秒。
